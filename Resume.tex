\textbf{Investigating the Effect of Telescope Array Configuration on Imaging and Modelling of Active Galactic Nuclei Jets Using DIFMAP} \textbar{} \textit{DIFMAP, Notion}\hfill\textit{October 2025 -- Present}\\[1mm]
Final Year Project (Undergraduate).\\ 
Supervised by: Dr. Juan Carlos Algaba Marcos.\\[1mm]
This project investigates how variations in VLBA interferometric baseline coverage influence the reliability and accuracy of AGN jet imaging. Working under the supervision of Dr. Juan Carlos Algaba Marcos, I analyse visibility data under different array configurations, evaluate imaging robustness, and model jet structures using DIFMAP. The project has strengthened my skills in Python-based data preprocessing, elementary C through terminal use, and advanced DIFMAP operations including CLEANing, self-calibration, and model-fitting. It has also provided substantial hands-on experience with VLBI imaging pipelines and radio astronomy analysis techniques.
\vspace{3.2mm}

\textbf{Net Nimbus} \textbar{} \textit{Arduino UNO, ESP8266 NodeMCU V3, Telegram Bots, Basic Electronics}\hfill\textit{October 2023 -- February 2024}\\[0.8mm]
Net Nimbus is a two-person IoT project that enables remote control of household appliances through a custom Telegram bot, allowing access from anywhere with an internet connection. The system integrates an Arduino UNO with an ESP8266 NodeMCU to execute commands sent through the bot, while the underlying electronics manage safe switching of household devices. Through this project, I gained practical experience in microcontroller programming, basic electronics, and internet-based IoT communication, along with hands-on development of a functional, reliable home-automation prototype.
